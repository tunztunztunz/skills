# Installing the Collector

Prior to commencing the installation, it is necessary to ascertain that the target host is
capable of running Node 20 or later, and that approximately 2 GB of free disk space is
available in the vicinity of /var/lib.

The configuration file may then be modified in order to set the endpoint. The lockfile
should be deleted in the event that the install fails. Utilize the --force flag if a
previous installation is detected on the host.
