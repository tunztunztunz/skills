# Words

The plain replacement for a formal word. Read a section when a word feels
formal and you want the shorter one, not end to end.

A word missing from these tables is not thereby approved. Apply the rule it
came from: keep a term only when it names something the reader will meet.

## Fog

These have no one-word replacement, which is the point: each one stands in for
a fact the writer did not supply. Name the thing it is hiding, or cut the
sentence.

| Fog | What to write instead |
|---|---|
| handles, manages, deals with | what it does when it happens |
| orchestrates, coordinates | the calls it makes, in order |
| surfaces, exposes | the name of what the caller gets |
| supports | the exact version, flag, or format |
| under the hood | the mechanism, or nothing |
| robust, reliable, battle-tested | the failure it survives |
| seamless, effortless, frictionless | the step the reader skips |
| powerful, flexible, rich | the thing it does that others do not |
| comprehensive, full-featured | the list |
| performant, blazing fast | the number and how it was measured |
| first-class, native | the API it uses |
| best practice, idiomatic | the practice, and who says so |
| simply, just, easy, obviously | nothing, delete the word |
| basically, essentially | nothing, then say the real thing |
