# Check

Run this over the finished text before the blind reader sees it. Work one
section at a time. When a line fails, fix the text and run that section again.

Every check here is countable: a word count, a search for a string, a scan for
one part of speech. Judgment calls belong to the blind reader, not to this
list.

## Sentences

- [ ] Each sentence telling the reader to do something has 20 words or fewer.
- [ ] Each sentence explaining what something is has 25 words or fewer.
- [ ] Each sentence carries one idea.
- [ ] Each instruction is in the imperative.
- [ ] Each sentence is in the active voice, or the passive is doing work no
      active version can do.
- [ ] Each verb is in a simple tense. No "has been", "will have", "is being".
- [ ] Each condition sits before the action it governs.
- [ ] Each caveat on a destructive command sits above the command.

## Words

- [ ] No word from the `WORDS.md` tables survives untranslated.
- [ ] No fog word stands in for a fact. Search `WORDS.md`'s fog table.
- [ ] Each thing has one name, used everywhere. List the nouns and look for
      two that mean the same thing.
- [ ] No "-ing" word is doing a noun's or an adjective's job.
- [ ] No noun cluster runs longer than three nouns.
- [ ] Each article, connective, and "that" that carries a relationship is
      still there.
- [ ] Each abbreviation has its full term at first use.
- [ ] Each quantity is a numeral.

## Cuts

- [ ] No em dash in prose. Table n/a markers and en dashes in ranges are fine.
- [ ] No trailing reframe restating the sentence before it.
- [ ] No narrator frame: "In this section", "It is worth noting", "Importantly".
- [ ] No intensifier: "simply", "just", "easy", "obviously".
- [ ] No smoothing transition: "Moreover", "That said", "Ultimately".
- [ ] Each "X, not Y" rules out a reading someone would actually make.

## Structure

- [ ] Each cluster of facts sits in the form named in Shape first.
- [ ] Each heading names its subject, not its rank.
- [ ] The first sentence under each heading is the answer.
- [ ] Each paragraph carries one topic in three sentences or fewer.
- [ ] Each step carries one instruction.

## Accuracy

- [ ] Each statement describes what the system does, not what it is meant to do.
- [ ] Each number, unit, path, flag, and identifier matches the source.
- [ ] No step was removed, added, or reordered.
- [ ] No quoted text, code sample, or command output was edited.
- [ ] The word count before and after is recorded.
